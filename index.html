Digital Pressure Monitoring Cluster (V1 MVP)

A real-time embedded system for railway applications that monitors multiple pressure sensors and shows the readings with high responsiveness and reliability.

Key highlights

  • STM32 with an optimised single-loop architecture and no RTOS
  • Deterministic loop cycle of 135 ms
  • 6 CAN-based pressure sensors, monitored up to 11 bar
  • Data logged to SD card every 3 seconds

Features

  • Real-time pressure gauge visualisation
  • Warning, error and system status indication
  • USB firmware update with fallback mechanism
  • USB extraction of logged data from the SD card
  • Full control using only 4 hardware buttons

My contribution

  • Designed the complete firmware architecture and system flow
  • Implemented CAN communication for a multi-node sensor network
  • Developed the multi-function button handling logic
  • Integrated SD card logging and USB data transfer
  • Tuned execution timing to hold a deterministic 135 ms loop

Pressure Monitoring Cluster, Advanced (V2)

The next generation of the cluster, moving from a bare-metal design to a scalable RTOS platform with an advanced GUI, external memory and industrial-grade reliability.

Key improvements over V1

  • FreeRTOS multitasking architecture
  • External QSPI flash for application execution
  • External RAM for GUI and buffering
  • eMMC storage over SDMMC
  • High-resolution LVDS display with TouchGFX
  • Multiple sensor vendors with auto-detection
